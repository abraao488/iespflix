# IespFlix

Projeto academico separado por responsabilidade:

- `back-end/`: API REST Spring Boot 3.5.x com Java 21.
- `front-end/`: aplicacao React + Vite consumindo a API via proxy `/backend`.

## Rodar backend

```bash
cd back-end
.\mvnw.cmd spring-boot:run
```

## Rodar frontend

```bash
cd front-end
npm install
npm run dev
```
